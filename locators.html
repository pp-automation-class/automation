Playwright locators

Most resilient first. Click a control — the hit log shows which locator fired.

waiting for interaction…

1 Role

get_by_role — accessibility name. Prefer this.

page.get_by_role("textbox", name="Username").fill("standard_user")
page.get_by_role("button", name="Login").click()

2 Label

get_by_label — associated <label for>.

page.get_by_label("Email").fill("student@example.com")

3 Placeholder

get_by_placeholder — only if there's no proper label.

page.get_by_placeholder("Password").fill("secret_sauce")

4 Text

get_by_text — visible copy. Substring match by default.

Products

expect(page.get_by_text("Products")).to_be_visible()
page.get_by_text("Add to cart").click()

5 Alt text

get_by_alt_text — images.

page.get_by_alt_text("Swag Labs").click()

6 Title

get_by_title — tooltip / title attribute.

Inventory 
page.get_by_title("Open inventory").click()

7 Test id

get_by_test_id — data-testid. Use when user-facing attrs don't exist.

page.get_by_test_id("checkout").click()

8 CSS / XPath

page.locator — last resort. IDs and classes break on restyle.

page.locator("#user-name").fill("standard_user")
page.locator("#login-button").click()
page.locator("xpath=//button[@id='login-button']").click()
